# ID-card extraction status

The protected `/register` page accepts one JPEG, PNG, or WebP image up to 10 MB. The browser previews the selection. The server checks the session, request size, actual image bytes, and decoded pixel count, then runs local English OCR with Sharp and Tesseract.js. It returns raw text and fields parsed only from explicit labels. Missing or conflicting fields remain empty, student-ID leading zeros remain intact, and unknown clear labels are shown separately.

The image and result are temporary: the API does not write either to SQLite or disk, and leaving or refreshing the page clears the browser result. The page does not save a reviewed profile. English printed text on a clear card works best; OCR may miss, misread, or mislabel text. Students must inspect the raw text and candidates. Linways retrieval, correction/merge, and profile saving remain separate pending modules.

On Windows x64 with Node 24.19.0, `npm.cmd install` installs the pinned `sharp`, `tesseract.js`, and `@tesseract.js-data/eng` packages. The English asset is `node_modules/@tesseract.js-data/eng/4.0.0_best_int/eng.traineddata.gz`; no OCR API key or runtime download is needed. The synthetic card took roughly 350–460 ms for OCR in integration checks. Tesseract may print a nonfatal DPI warning for images derived from SVG.

Verification on 2026-10-04: 57 unit/integration tests passed; the production build, lint, and typecheck passed. Four ID-card browser scenarios passed on desktop Chrome and the 375 px phone-sized website viewport: unauthorized redirect; synthetic-card preview/extraction/replacement with raw text and leading-zero student ID; blank-image failure/retry; and unsupported, oversized, and corrupt-image rejection/retry. The complete browser suite passed 14 tests across both viewports. Chrome DevTools inspection found a labeled upload control, announced status region, no console warnings/errors, and no horizontal overflow at 375 px. The browser test runner's own server may linger during shutdown on this Windows environment even after all assertions pass.
